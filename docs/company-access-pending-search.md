# Search approved offices and review candidates

The map drawer previously indexed only approved offices, so SMIC and Huahong could not be found even though their POIs existed in the review queue. The explicit review build now creates a separate compact `candidate-search.json` from the same immutable Console bundles. It contains 1,067 non-approved records: 553 pending, 450 needs_review and 64 rejected. All 207 approved office features and all historical decisions remain unchanged.

Search uses the shared Chinese/English alias index. New source-backed mappings bind exact canonical names and stable AMap IDs, not fuzzy identities. No aliases apply to unrelated cafés, gates or parking facilities. Company names are unchanged. Approved results follow the current reach; candidate results search all available reaches and disclose exact membership/current-range mismatch. This avoids interpreting a selected 10-minute reach as no candidate inventory.

The drawer prioritizes explicit important-company annotations, with shortcuts for 中芯国际, 华虹, 环旭 and 豪威. Each candidate displays its actual review status and does not count as an approved office. Clicking a candidate displays a single amber hollow MapLibre selection ring with an unapproved label. It is a separate, unclustered source, never appended to approved office GeoJSON or cluster counts. Closing the drawer clears it; style replacement restores it; approved-point and cluster clicks clear the candidate selection. No DOM markers or hidden hit layers.

The review link carries the exact provider ID to the existing Console. It clears unrelated filters, selects the correct row and highlights it. Locked historical decisions remain read-only. New evidence cards are separate from decisions and suggestions; no automatic accepts, confidence upgrades or changes to source coordinates.
